# Introduction

These are the working docs for a design take-home: an app that puts a high street's independent shops in one place, so a shopper can see what is available nearby right now, buy it, and collect it or have it delivered.

## What this is

A working record, not a presentation. It's where I log the work I do with AI agents: what we researched, what I decided and why, what the agents produced, and what I kept or threw away. It's written for me, for the agents and for anyone else working on this with us.

The final output for review is a recorded walkthrough of the work, with this record behind it as the evidence. So these pages favour completeness and traceability over storytelling.

## How the work is organised

The docs follow the order the work happens in. Each phase only opens once the one before it has given it something to stand on.

| Phase | Question it answers | Status |
| --- | --- | --- |
| Discover | What is a high street today, who shops there, and what do they say about it? | In progress |
| Define | Findability or transaction, for which shopper, under which assumptions? | Not started |
| Develop | What does the journey look like, and which concept holds up? | Not started |
| Deliver | The prototype, the polished screens and, if it earns its place, a running app | Not started |

The [decision log](decision-log.md) records the calls that shaped the process, in the order they were made.

## How to read the evidence

Claims about people come from public posts, quoted word for word with the author's public handle, the network, the date and a link to the original. Everything is from the 18 months before November 2026. Where a page draws a conclusion from that material, it says so, and the [sources](discover/sources.md) page lists every link in one place.

## How it was made

I directed the work; AI agents (Claude Code as the main one, Codex for reviews) did most of the collecting, coding and drafting. Every page says how AI was used in that step, and [how AI was used](process/ai-log.md) logs what each agent was asked, what came back and what I threw away or fixed. The prototype is built in code; Figma and Apple Freeform are used only for exploration.
